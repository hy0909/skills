# 한국어 AI 글 패턴 목록 — 전/후 예시

`SKILL.md` §3의 상세판. 윤문 모드 진단 때 이 순서로 훑는다. 하나가 한 번 나오는 건 괜찮다. 여러 패턴이 한 문단에 겹치거나 하나가 반복될 때 AI 글로 읽힌다.
참고 출처: im-not-ai(한글 AI 티 제거기) 10대 분류, woonjangahn 상투 패턴 gist, 위키백과 "AI 글쓰기 징후", 폭스씨지·요즘것들 블로그 전후 예시.

## A. 번역투

| 전 | 후 |
| --- | --- |
| AI 기술을 통해 효율을 높일 수 있다 | AI로 효율을 높인다 |
| 이에 있어서 중요한 점은 | 여기서 중요한 건 |
| 시스템에 의해 생성된 파일 | 시스템이 만든 파일 |
| 이 식당은 서울 강남구에 위치해 있습니다 | 이 식당은 서울 강남구에 있어요 |
| 이 제품은 뛰어난 편의성을 제공함에도 불구하고, 다소 무거운 무게를 가지고 있습니다 | 써보니 편하긴 한데, 생각보다 좀 무겁다 |
| 이 소프트웨어는 우리의 작업 시간을 단축시켜 줍니다 | 이 소프트웨어를 쓰면 작업 시간이 줄어든다 |
| 결과가 도출되어졌다 | 결과가 나왔다 |
| 사용자에 대해 알림을 제공한다 | 사용자에게 알린다 |

체크: `~를 통해`, `~에 있어서`, `~에 의해`, `~되어지다`, `위치해 있다`, `~함에도 불구하고`, `~를 가지고 있다`, `~에 대해`, `그/그녀`, `~시켜 주다`.

## C. 구조 패턴

| 전 | 후 |
| --- | --- |
| 첫째, 비용이 줄어든다. 둘째, 속도가 빨라진다. 셋째, 오류가 줄어든다. | 비용이 줄고 속도가 빨라진다. 오류도 줄어든다. |
| 효율성, 생산성, 그리고 창의성을 높일 수 있습니다 | 일이 빨라진다 |
| **확장성:** 시스템은 확장 가능하다. **보안:** 보안이 강화됐다. | 서버를 늘려도 느려지지 않고, 로그인 정보는 암호화된다. |
| 왜 중요할까요? 이유는 단순합니다. | (삭제 후 바로 본문) |
| 이것은 단순한 도구가 아닙니다. 새로운 패러다임입니다. | 이 도구는 검색 방식을 바꾼다. |
| 국내뿐만 아니라 해외에서도 주목받고 있습니다 | 해외 3개 매체가 다뤘다 [확인 필요] |

체크: `첫째·둘째·셋째`, 3개 나열, 볼드 소제목 나열, 수사적 질문+즉답, `단순한 ~가 아니라`, `~뿐만 아니라 ~도`, 대시(—), 이모지 불릿, 연결어미 뒤 쉼표 남발.

## D. 상투 관용구

| 전 | 후 |
| --- | --- |
| 결론적으로, 이는 시사하는 바가 크다. | (삭제) |
| 이를 충분히 고려하는 것이 중요합니다. | 이걸 빠뜨리면 승인 버튼이 안 보인다. |
| 지속적으로 모니터링할 필요가 있습니다. | 매주 월요일 대시보드를 확인한다. |
| 중요한 전환점을 의미한다 | 크게 변했다 |
| 핵심은 다음과 같다. | (삭제 후 바로 내용) |

체크: `결론적으로`, `시사하는 바가 크다`, `주목할 만하다`, `~하는 것이 중요합니다`, `~할 필요가 있다`, `이유는 단순하다`, `핵심은 다음과 같다`, `중요한 점은`, `~라고 할 수 있습니다`, `~다는 점에서 주목할 만합니다`, `~의 시대`, `상상해 보세요`, `~살펴보겠습니다` 도입부.

## E. 리듬 균일

| 전 | 후 |
| --- | --- |
| 버튼을 누릅니다. 모달이 열립니다. 값을 입력합니다. 저장을 누릅니다. | 버튼을 누르면 모달이 열린다. 값을 넣고 저장. 그러면 목록으로 돌아간다. |
| 기존 컴포넌트(버튼·입력창처럼 화면을 이루는 부품)는 있었다. 하지만 제품마다 화면 구성과 사용 흐름이 달라 그대로 가져다 쓰기 어려웠다. | 기존 컴포넌트는 있었지만, 제품마다 화면 구성과 사용 흐름이 달랐기 때문에 그대로 가져다 쓰기 어려웠다. |

체크: 문장 길이가 다 비슷한가. `~습니다` 세 번 연속. `~합니다, ~됩니다, ~있습니다` 교대 반복. 같은 구조 세 번 연속. **짧은 문장 + 문두 `하지만/그래서` 짧은 문장** 연속(대조·원인을 쪼갠 흔적). 서술 문장 한가운데 끼어든 괄호 설명.

## F. 수식·중복

| 전 | 후 |
| --- | --- |

## I. 형식명사·추상 표현

| 전 | 후 |
| --- | --- |
| 기업은 변화하는 시장 환경에 효과적으로 대응하기 위해 전략적 접근이 필요하다. | 구매가 온라인으로 옮겨가서, 기업은 온라인 판매 채널을 늘리거나 고객 데이터로 맞춤 마케팅을 짜야 한다. |
| AI 기술은 현대 기업 경영에서 매우 중요한 역할을 한다. | AI가 고객 데이터로 소비 패턴을 예측하면, 상품 기획과 마케팅을 더 구체적으로 짤 수 있다. |
| 이러한 변화는 긍정적 측면과 부정적 측면을 모두 가지며 균형 잡힌 접근이 필요하다. | 기술 도입보다 구성원이 적응할 환경을 만드는 게 더 중요하다고 봤다. |

체크: `~것이다`, `~점`, `~할 필요가 있다`, `중요하다`, `필요하다`, `시사한다`, `기여한다`, `역할을 한다`.

## K. 윤문이 오히려 만드는 AI 티 — 억지 수정

원문이 사람 글인데 규칙을 기계적으로 적용하면 생기는 패턴. 2026-09-16 디자인 시스템 개요 윤문에서 실제로 나왔다.

| Claude 수정(나쁨) | 원문 또는 사용자 수정(좋음) | 무엇이 문제였나 |
| --- | --- | --- |
| 기존 컴포넌트(버튼·입력창처럼 화면을 이루는 부품)는 있었다. 하지만 제품마다 … | 기존 컴포넌트는 있었지만, 제품마다 화면 구성과 사용 흐름이 달랐기 때문에 그대로 가져다 쓰기 어려웠다. | 대조를 쪼개 문두 `하지만`, 서술 중 괄호 설명 |
| AI 결과물을 팀 기준에 맞춰 고치는 수고가 준다. | 결과물을 팀 기준에 맞춰 다시 손보는 일을 줄일 수 있다. | 반복 피하려 억지 동사(`수고가 준다`) |
| 화면을 다르게 해석해 생기는 수정도 막는다. | 화면을 다르게 이해해서 생기는 수정도 줄이려 한다. | 억지 동의어(`막는다`), 완곡 어미를 지운 딱딱함 |
| 베리언트(한 컴포넌트의 상태별 변형) | 형태별 구분 | 괄호 설명 대신 우리말 |
| 공통으로 유지할 부분과 바꿀 부분의 기준도 없었다. | 무엇을 그대로 쓰고 무엇을 바꿔도 되는지 정해져 있지 않았다. | 한자어 명사구 → `~ㄴ지` 절 |
| 디자인과 개발의 반복 작업을 줄인다 (소제목) | 같은 일을 다시 하는 시간을 줄인다 | 한자어 명사 소제목 → 일상어 문장 |
| 디자인과 코드의 이름과 구조를 맞춘다 (소제목) | 디자인과 코드가 같은 대상을 같은 이름으로 부르게 한다 | 추상 명사 → 구체 동작 |

체크: 윤문 뒤 바뀐 문장마다 "원문보다 나은가"를 묻는다. 아니면 되돌린다.

## 진단 문장 예시 (윤문 모드 1단계)

> 1. 번역투 — "~를 통해"가 4번, "~에 있어서" 1번.
> 2. 어미 — 2문단이 "~습니다"만 7문장 연속.
> 3. 추상 — "중요한 역할", "효과적으로 대응" 등 무엇을 어떻게 하는지 없는 문장 3개.
> 4. 구조 — 첫째·둘째·셋째 나열 1회, 3개 나열 2회.
> 5. 사례 없음 — 숫자·화면·상황이 하나도 없다.
