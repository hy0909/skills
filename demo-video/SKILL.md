# demo-video: 서비스 시연 영상 만들기

참고 스킬: motion-replicate (Affitok「Claude로 모션 따라 만들기」 가이드)
https://www.affitok.ai/resources/claude-motion-guide

motion-replicate는 움직임을 "부드럽게" 같은 말 대신 프레임, 값, 곡선 숫자로 적게 하는 스킬이다. 이 스킬은 그 규칙을 실제 화면 녹화 영상의 자막 카드, 인트로·아웃트로, 확대·축소에 적용한다. motion-replicate는 위 페이지에서 `motion-replicate.zip`을 받아 `unzip motion-replicate.zip -d .claude/skills/`로 함께 설치해 둔다.

## 언제 쓰나

- 고객사나 심사 쪽에서 "실제 동작 시연 영상"을 달라고 할 때
- 관리자 화면 기능(로그인, 2단계 인증, 등록, 업로드, 수정, 삭제, 변경 기록)을 한 번에 보여 줘야 할 때
- 같은 형식의 영상을 다른 서비스에서도 다시 만들 때

## 두 가지 버전

| 버전 | 화면 | 쓰는 때 |
|---|---|---|
| A. 확대·축소 있음 | 클릭하거나 입력하는 순간에만 그 위치로 확대했다가 전체 화면으로 돌아옴 | 작은 버튼·입력 칸이 많아서 어디를 누르는지 크게 보여 줘야 할 때 |
| B. 확대·축소 없음 | 처음부터 끝까지 전체 화면 | 화면 전체 흐름을 그대로 보여 주는 게 나을 때 |

프롬프트 전문은 `references/prompt-zoom.md`(A), `references/prompt-no-zoom.md`(B)에 있다. 대괄호 `[ ]` 안만 서비스에 맞게 바꿔서 쓴다.

## 진행 순서

1. 보여 줄 기능과 순서, 테스트 글을 실제 사이트에 공개로 올려도 되는지 사용자에게 먼저 확인한다. 운영 DB에 글을 쓰고 지우는 일이라서 승인 없이 하지 않는다.
2. Playwright로 사용자 PC의 크롬을 띄워 녹화한다. 비밀번호와 인증번호는 사용자가 그 창에 직접 입력하고, 관리자 화면이 열리면 나머지는 자동으로 조작한다.
3. 편집 단계에서 로그인 대기 구간을 자르고, 확대·축소(버전 A)와 자막 카드, 인트로·아웃트로를 붙인다.
4. 2초 간격 장면 모음 이미지를 만들어 확대 시점과 자막이 화면과 맞는지 직접 확인한다.
5. 테스트 글이 DB에서 지워졌는지 확인하고 영상 파일을 보낸다.

## 녹화하면서 겪은 문제와 대응

| 문제 | 대응 |
|---|---|
| 녹화 창이 다른 창 뒤에 숨어서 사용자가 못 찾음 | 창을 띄운 직후 맨 앞으로 가져온다 |
| 로그인을 기다리다 시간 초과로 녹화가 꺼짐 | 로그인 대기는 시간 제한 없이 기다린다 |
| 녹화 파일이 실제 시간보다 8% 정도 늘어져 자막이 점점 밀림 | 화면 왼쪽 위 색 칸으로 장면 번호를 표시하고, 장면 시각과 프레임 번호를 직선으로 맞춰 보정한다 |
| 색 칸 번호가 28번을 넘으면 빨강 값이 255에서 멈춰 구분이 안 됨 | 빨강·파랑 두 색으로 나눠 64번까지 구분한다 |
| 압축 때문에 색이 번져 엉뚱한 번호로 읽힘 | 또렷한 값이 두 프레임 연속일 때만 인정한다 |
| 브라우저 기본 확인 창(confirm)은 녹화에 안 찍힘 | 서비스에 화면 안 확인 모달을 만들어 쓴다 |
| 쿠키 동의창이 자막을 가림 | 녹화 전에 localStorage에 선택값을 넣어 둔다 |
| 파일 저장소 주소(외부 서비스 이름)가 본문·첨부 목록에 그대로 보임 | 서비스가 짧은 경로(`files/...`)만 적고 화면에 띄울 때 실제 주소로 바꾸게 고친다 |
| 글자를 칠 때마다 미리보기 이미지가 다시 불러와지며 덜컹거림 | 미리보기를 새로 그릴 때 이미 불러온 이미지 요소를 그대로 옮겨 쓰게 고친다 |
| 클릭하지 않은 목록·상세·기록 화면까지 확대돼서 전체가 안 보임 | 확대는 클릭·입력 순간에만 하고, 목록·상세·기록은 전체 화면으로 둔다 |
| 로그인 화면에서 마우스가 오가고 인증번호를 기다리는 장면이 길게 남음 | 입력 칸이 가로 절반 이상 바뀌는 순간을 찾아 그 직전까지 잘라 낸다 |

## 규칙

- 움직임은 프레임, 값, 곡선 숫자로만 적는다. "부드럽게", "빠르게"는 쓰지 않는다.
- 녹화, 측정, 출력 프레임 수를 30fps 하나로 맞춘다.
- 측정하지 못한 값은 "가정"이라고 적는다.
- 비밀번호, 인증번호, 계정 생성은 사용자가 직접 한다.
- 영상에 외부 서비스 이름이나 내부 주소가 보이지 않는지 마지막에 한 번 더 확인한다.
