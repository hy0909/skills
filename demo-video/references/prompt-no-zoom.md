# 버전 B: 확대·축소 없음

대괄호 `[ ]` 안만 서비스에 맞게 바꿔 Claude Code에 붙여 넣는다. 작은 글씨가 잘 안 보이면 녹화 창을 1440x810으로 줄여서 같은 1920x1080으로 키운다.

```text
참고 스킬: motion-replicate (Affitok「Claude로 모션 따라 만들기」 가이드)
https://www.affitok.ai/resources/claude-motion-guide
스킬은 위 페이지에서 motion-replicate.zip을 받아 `unzip motion-replicate.zip -d .claude/skills/`로 설치해 둔 상태야.

motion-replicate 스킬 규칙대로 [사이트 주소, 예: https://service.com/admin/] 시연 영상을 만들어 줘.

[목적]
- 실제 운영 화면에서 [보여 줄 기능, 예: 로그인(2단계 인증), 글 등록, 파일 업로드, 수정, 삭제, 변경 기록]이 실제로 동작하는 걸 증빙하는 영상이야.
- 최종 파일: 1920x1080, 30fps mp4. 녹화, 측정, 출력 모두 30fps로 맞춰.

[녹화]
- Playwright로 내 PC의 크롬(channel: "chrome")을 화면에 띄우고, 창 크기 1600x900으로 recordVideo 녹화해.
- 로그인 비밀번호와 인증번호는 내가 그 창에 직접 입력할게. 관리자 화면이 열릴 때까지 시간 제한 없이 기다리고, 열리면 나머지는 자동으로 조작해.
- 창은 띄운 직후 맨 앞으로 가져와 줘.
- 쿠키 동의창이 뜨지 않게 localStorage에 미리 선택값을 넣어 둬. [키 이름, 예: service-consent]
- 영상에 보이는 커서를 페이지에 직접 그려 줘. 검은 화살표에 흰 테두리, 28px.
- 클릭할 때는 보라색(#A46BFF) 원 두 겹이 64px에서 1.5배로 퍼지며 0.7초 동안 사라지게 해 줘. 두 번째 원은 120ms 늦게 시작해.
- 마우스는 순간이동하지 말고 목표까지 여러 단계로 움직여. 클릭 전에 0.2초 멈춰.
- 브라우저 기본 confirm 창은 영상에 안 찍히니까, 확인이 필요한 동작은 화면 안 모달로 보이게 해.
- 테스트 글 내용은 홈페이지 맥락에 맞게 그럴듯하게 정해 줘. 시연이 끝나면 지우고, DB에서 지워졌는지 확인해.

[장면 기록]
- 단계마다 장면 번호를 기록하고, 화면 왼쪽 위 14px 칸의 색으로 그 번호를 표시해 줘. 빨강 = (번호 % 16) × 16, 초록 255, 파랑 = floor(번호 / 16) × 64.
- 편집할 때 이 색 칸을 읽어서 영상 속 프레임 번호를 찾고, 다 쓰고 나면 칸을 지워.
- 녹화 파일은 실제 시간보다 늘어질 수 있으니 장면 시각과 프레임 번호를 직선으로 맞춰서 보정해.

[화면 구성]
- 확대·축소 없이 처음부터 끝까지 전체 화면으로 보여 줘. 녹화한 1600x900 화면을 1920x1080으로 키우기만 해.
- 대신 클릭 원 효과와 커서 이동은 그대로 넣어서 어디를 누르는지 보이게 해.

[편집]
- 로그인 구간에서 기다리는 장면은 잘라 내. 첫 화면은 0.5초만 보여 주고 이메일 칸을 누르는 순간으로 건너뛰어.
- 인증번호 화면은 1.2초만 보여 주고 첫 숫자를 입력하는 순간으로 건너뛰어.
- 입력 칸이 가로 절반 이상 바뀌는 순간을 입력 시작으로 봐. 커서만 움직인 건 무시해.

[자막 카드: 화면 왼쪽 아래]
- 위치: left 40, bottom 40. 안쪽 여백 28 × 40px, 모서리 20px.
- 배경: 남색 #05060D 94%. 테두리: 2px 짙은 회색 #4A4F68.
- 번호 원: 60px, #A46BFF, 숫자 28px.
- 제목: 40px 굵게, 흰색. 설명: 28px, #C9CDE0. 제목과 설명 사이 8px.
- 등장: 0~14프레임, 투명도 0→1, 아래에서 24px→0, cubic-bezier(0.16, 1, 0.3, 1). 번호 원은 4~13프레임에 0.6→1배.
- 퇴장: 8프레임, 투명도 1→0, 0→12px 아래로, cubic-bezier(0.7, 0, 0.84, 0).
- 단계별 문구: [단계 이름과 설명을 나열]

[인트로·아웃트로]
- 인트로 4초: 남색 배경, 로고, 제목 「[영상 제목]」, 날짜, 단계 목록. 요소마다 4프레임씩 늦게 등장.
- 아웃트로 5초: 「시연을 마쳤습니다」와 단계 목록. 각 단계 앞 체크 표시가 6프레임 간격으로 0.4→1배로 커지며 나타나.
- 컷은 페이드 없이 바로 넘겨.

[규칙]
- 프롬프트와 코드에 "부드럽게", "빠르게" 같은 말 대신 프레임, 값, 곡선을 숫자로 적어.
- 측정하지 못한 값은 "가정"이라고 표시해.
- 다 만들면 2초 간격 장면 모음 이미지로 자막 시점이 맞는지 직접 확인하고 영상 파일을 보내 줘.
```

색상 값은 예시로 남색·보라색·회색을 적어 두었다. 서비스의 브랜드 색으로 바꿔서 쓴다.
